# JPC -- AI-Powered Lead Management Automation

## Project Overview

JPC is an automated lead management workflow built with n8n. It collects
lead information through a webhook, processes the data, updates Google
Sheets, and sends email notifications using Gmail.

## Tech Stack

-   **n8n** -- Workflow automation
-   **Webhook** -- Lead data collection
-   **Google Sheets** -- Lead data storage and updates
-   **Gmail** -- Automated email notifications

## Workflow

1.  Receive lead information through a webhook.
2.  Process and organize the incoming data.
3.  Update the corresponding record in Google Sheets.
4.  Send an email notification through Gmail.
5.  Complete the workflow automatically.

## Key Features

-   Automated lead data collection
-   Google Sheets integration
-   Automatic row updates
-   Gmail email notifications
-   Reduced manual data entry

## Workflow Architecture

`Webhook → Data Processing → Google Sheets → Gmail`

## Project Status

Completed and tested.

## Business Benefits

-   Reduces repetitive manual work
-   Helps keep lead records organized
-   Speeds up email communication
-   Reduces the risk of manual data-entry errors
